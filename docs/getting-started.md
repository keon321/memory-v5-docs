# Getting started

## 1. Open the connection page

Use:

https://memory.5188688.xyz/start

Follow the connection flow shown there.

## 2. Use a real long-running task

In the chat you want to continue, ask Memory V5 to save the task and prepare continuation.

The goal is not to create a generic summary. The saved state should capture the current goal, decisions, completed work, rejected routes, unresolved items, and next action.

## 3. Open a new chat

Paste the continuation package into a new ChatGPT chat.

The new chat should first report what it recovered.

## 4. Confirm or correct

If the recovered state is accurate, confirm it and continue.

If something important is missing or wrong, correct it before continuing.

## 5. Judge the product by one question

After switching chats:

> Can you continue the original work without re-explaining the project?

That is the primary test.
