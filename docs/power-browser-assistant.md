# Power 浏览器助手｜手动安装

Power 是 Memory V5 的可选浏览器助手。

**只加 MCP 也能正常使用 Memory V5。** Power 只是让“换 Chat”更省事：点一下 Power，它会准备续聊内容并复制到剪贴板。你再打开新 Chat，粘贴发送即可。

## 下载

[下载 Power 0.7.0 ZIP](../downloads/memory-v5-power-0.7.0.zip)

`66d3f10be09482817a109d5424d8935d6b391d790a40c27227e9976b6f08e5fc`

## Chrome 安装

1. 下载 ZIP，并解压。
2. 打开 `chrome://extensions/`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 `memory-v5-power-0.7.0` 文件夹。
6. 打开或刷新 ChatGPT。

如果安装成功，ChatGPT 页面里会出现 Power 按钮。

## 怎么用

平时正常聊天。

准备换 Chat 时：

1. 点一下绿色 Power；
2. 等它提示续聊内容已经复制；
3. 打开一个新 Chat；
4. 粘贴并发送；
5. 检查恢复内容，确认没问题以后再继续。

Power 不会替你自动打开新 Chat，也不会自动发送消息。

## 更新

手动安装版不会像 Chrome 商店版那样自动更新。网站发布新版后，需要重新下载并替换。

## 安全提醒

不要把密码、API Key、Cookie、OAuth 访问令牌或续聊令牌发给别人。
