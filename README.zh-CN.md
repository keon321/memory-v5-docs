# Memory V5

**换一个新对话，继续原来的工作。**

Memory V5 用来解决一个很具体的问题：

> ChatGPT 长对话变慢、达到上限或必须换新对话时，怎样让新对话准确接着原任务继续，而不是重新解释一遍。

它适合持续数天到数周的开发、研究、产品、写作、学习等长期任务。

## 为什么普通总结不够

普通总结很容易丢掉真正影响继续工作的内容：

- 任务真正目的；
- 已经确定的决定；
- 已完成工作；
- 已经否决的路线；
- 尚未解决的问题；
- 最后停在哪里；
- 下一步应该做什么。

Memory V5 保存的是结构化任务状态，而不是整段聊天记录。

## 怎么用

1. 在当前长期任务里保存任务状态；
2. 新建一个 ChatGPT 对话；
3. 把续聊内容发到新对话；
4. 新对话先汇报恢复出的状态；
5. 你确认正确以后，再继续原任务。

如果任务身份不确定，系统应该停止，而不是按标题或相似话题猜测。
