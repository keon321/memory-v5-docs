# TaskOnward

**换一个新对话，继续原来的工作。**

TaskOnward 解决一个具体问题：长期 AI 任务必须换新对话时，让新对话准确接着原任务继续，而不是重新解释一遍。

## 为什么需要它

普通总结容易丢掉真正影响继续工作的内容：

- 任务真正目的；
- 已确定的决定；
- 已完成工作；
- 已否决路线；
- 尚未解决的问题；
- 下一步应该做什么。

TaskOnward 保存结构化任务状态，而不是完整聊天记录。

## 怎么用

1. 保存当前任务状态；
2. 打开新的 Chat；
3. 带入续聊内容；
4. 检查恢复结果；
5. 确认后继续原任务。

如果任务身份不确定，系统应该停止，而不是按标题或相似话题猜测。
